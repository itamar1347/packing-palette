# Packing Palette (פלטת אריזה)

A Hebrew, right-to-left site. Enter a destination, travel dates and optional activities, and it returns:

- **Weather for those dates.** The live forecast when the trip is within 16 days. Otherwise, what actually fell on the same dates in the three most recent years (Open-Meteo).
- **Three iconic photographs** of the place, from Wikipedia, Wikidata and Wikimedia Commons, each credited.
- **A four-color palette** read from each photograph's pixels.
- **A packing list with quantities**, sized by trip length, weather and activities.
- **A song of the day.** A daily pick from 40 The Weeknd songs, with a 30-second preview, cover art and links (iTunes). It can be swapped for another song, and the choice is remembered for that day.

Built with React and Vite. It needs no API keys.

```bash
npm install
npm run dev
```
